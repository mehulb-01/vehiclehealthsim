About this model

Each sensor is scored 0–1 against its safe operating band, then a logistic regression (trained on 12,000 simulated duty cycles, ROC‑AUC 0.78) turns those scores into a failure probability. Health score is a separate, simpler average of the same risk values, so the two numbers can disagree — the model is meant to flag risk before the vehicle visibly "feels" unhealthy.
Drag any slider for manual control (pauses the simulation). Vehicle speed is shown for context only and is not used by the model.
